# tb3-house preset

`map.pgm` / `map.yaml` are the TurtleBot3 house SLAM map from
[ROBOTIS-GIT/turtlebot3_simulations](https://github.com/ROBOTIS-GIT/turtlebot3_simulations)
(Apache License 2.0, ROBOTIS CO., LTD.).

`map.grid.json` and `thumb.png` are generated from them with `npm run convert-map`.
