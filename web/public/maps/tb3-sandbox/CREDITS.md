# tb3-sandbox preset

`map.pgm` / `map.yaml` are the example TurtleBot3 sandbox occupancy map from
[ros-navigation/navigation2](https://github.com/ros-navigation/navigation2/tree/main/nav2_bringup/maps)
(Apache License 2.0, Open Navigation LLC and contributors).

`map.grid.json` and `thumb.png` are generated from them with `npm run convert-map`.
