# small-house preset

`map.pgm` / `map.yaml` are the gmapping SLAM output shipped with
[aws-robotics/aws-robomaker-small-house-world](https://github.com/aws-robotics/aws-robomaker-small-house-world/tree/ros1/maps/turtlebot3_waffle_pi)
(MIT License, Copyright 2019 Amazon.com, Inc. or its affiliates).

`map.grid.json` and `thumb.png` are generated from them with `npm run convert-map`.
